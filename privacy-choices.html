Privacy Choices

PlateCost AI does not create user accounts. In the current release candidate, recipe and pricing data is stored locally and is not sent to an AI provider or PlateCost AI server.

What You Can Control

  • Delete saved menu estimates from inside the app.
  • Reset the current draft before a new estimate.
  • Contact support for privacy questions; this webpage cannot access or erase data stored on your device.

Remote Processing

Remote AI requests are unavailable in the current release candidate, so recipe and cost data is not transmitted to DeepSeek. If remote processing is introduced in a future release, the app will disclose the fields, recipient, and purpose and request consent before sending data.
